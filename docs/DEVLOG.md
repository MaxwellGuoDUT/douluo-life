## 🐞 今日调试记录

今天最大的工作其实不是写代码，而是学习如何 Debug。

遇到的问题：

点击按钮没有任何反应。

排查过程：

① 检查 HTML

确认按钮 id 正确。

② 检查 script

发现必须使用：

type="module"

才能使用 import/export。

③ 检查模块路径

确认：

app.js

↓

game.js

↓

player.js

引用路径全部正确。

④ 使用 console.log 调试

逐步确认：

- app.js 是否加载
- Game 是否创建成功
- Button 是否找到
- Click 是否触发
- startNewGame 是否执行
- Player 是否创建

最终成功定位问题并完成修复。

今天第一次完整体验了软件开发中的 Debug 流程。

## 💡 今日设计思考

今天确定了整个项目最重要的一条设计原则：

Game 管理整个游戏。

Player 保存玩家数据。

未来新增任何功能时，优先考虑：

"这个功能属于 Game，还是属于 Player？"

保持职责清晰，避免所有代码都堆积在一个文件中。
