## 一、最重要的口径区分

### 品质战斗力系数

| 武魂品质 | 等级战力加成系数 |
| --- | ---: |
| 低等 | 0% |

这组数值只参与战斗力计算，绝不是品质抽取概率。

### 品质抽取概率

品质抽取概率出现在本文第五节。它回答“本次觉醒进入哪个固有品质定义池”，由先天魂力决定，并且每一行总和为 100%。

建议在数据中使用不同字段：

```text
qualityGrade              固有品质
qualityCombatCoefficient  战斗力加成系数
qualityRollWeights        抽取权重或概率
```

## 二、设计原则

1. 先天魂力越高，多武魂、高品质和特殊天赋的概率单调增加。
2. 低天赋仍保留极小概率获得稀有结果，不设置绝对品质门槛。
3. 武魂品质是定义的固有字段：先抽目标品质，再从对应品质定义池抽具体武魂。
4. 武魂基础形态不受先天魂力影响。
5. 多武魂数量和品质会共同提高战力，必须联合检查，不能分别设计后直接相乘而不评估结果。
6. 所有概率都应使用整数权重保存；本文用百分比便于人工审阅。
7. production 只能抽取已经人工审定、主模式允许的武魂定义。

## 七、武魂基础形态概率

先天魂力不影响基础形态。负责人在 production 随机测试后选择按世界观稀有度调整五种基础形态权重：器、兽为主体，植物居中，食物和本体保持稀有。

| 基础形态 | 参考权重 | 归一化概率 |
| --- | ---: | ---: |
| 器 | 340 | 34.00% |
| 兽 | 360 | 36.00% |
| 植物 | 200 | 20.00% |
| 食物 | 60 | 6.00% |
| 本体 | 40 | 4.00% |
| 合计 | 1000 | 100.00% |

原“极致、神级、变异、邪灵”不再参与基础形态轮盘：

- 极致是固有品质；
- 神级目录拆回基础形态，必要时增加 `divine` 标签；
- 变异和邪灵作为定义标签或性质；
- 具体定义仍由“形态 + 品质 + canonLevel + 审定状态”共同筛选。

## 十、审定结论与剩余问题

Day 15 已确认并实现：

1. 先天0级概率为 5%；
2. 先天20级概率为 0.5%；
3. 数量矩阵按本文保存为整数权重；
4. 先天20级极致品质概率为 50%；
5. 每次觉醒只抽取一次品质，所有武魂槽位共享该结果，无隐藏衰减或重抽；
6. 品质战力系数叠加上限保持 100%。

仍待后续独立审定：特殊天赋目录、强度分层、互斥组、出现率和数量矩阵。本阶段没有把第八节建议值接入 production。
