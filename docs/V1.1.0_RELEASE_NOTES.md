# 斗罗人生模拟器 V1.1.0：神考、海神九考与问题恢复

版本：V1.1.0 · 2026-10-14（Asia/Shanghai）。正式发布记录以 GitHub 对应 tag 和 Release 为准。

这一版补齐了普通神考和海神岛奖励，并将海神独立九考接入完整的继承、继续人生及主动飞升流程。

## 新增与完善

- 斗一普通神考覆盖三级七考、二级八考、一级九考、神王九考，共33个奖励阶段；化形后沿用对应条件与流程。
- 海神岛黄、紫、黑、顶级考核的23个奖励阶段按实际资格与考次结算。
- 获得海神九考资格后立即开始独立九考，只允许与修罗共存，使用独立的一次性领奖记录。已有其他神位时不会再抽中海神机会。
- 海神继承后先等待选择：继续人生保留角色成长，主动飞升才结束这段人生。九考专属奖励和门槛为项目已确认规则。
- 显示真实路线、年龄、战力与当前神考进度，记事分类保留完整历史；系统说明不会使抽取记录错位。

## 修复与恢复

- 修复纯魂兽雷劫中元素奖励重复执行导致的中断，没有修改权重或随机算法。
- 修复候选全部耗尽后的合法快照无法读取：恢复后明确停在中断状态，保留待领奖、历史和随机进度，可手动保存、导出和复制有限问题信息。
- 覆盖存档仍需明确确认，取消不替换旧槽位；刷新后仍需主动读取。问题复制保留可选择的手动内容。

## 存档提示

本版斗一内容语义与旧版不同。请先导出原始备份，保留原版本继续旧人生；旧档不会自动迁移，槽位也不会自动改写。正常导出经过校验，原始备份保留原文本但不保证可读取。

仍为纯前端、手动本地8槽和JSON导入导出，没有账号、后端、云同步或自动保存。

8槽不代表浏览器容量无限；较长人生同时保存多个槽时可能空间不足。写入失败会保留原槽和当前人生，请用JSON导出保留备份。

## 验证范围与已知限制

人类、化形后海神九考、修罗共存、继承后继续及主动飞升已取得机制测试和真实桌面浏览器证据。覆盖取消/确认和实际复制粘贴已完成核对。

自然搜索在8分钟预算内运行26局、13,001次调用，九考资格与黄级资格均未命中；这些自然完成证据仍缺，不能把机制样本当作自然命中。部分来源内容仍可能遇到安全中断；尤其魂骨部位全部占满后，恢复可以保留状态，但奖励如何继续没有明确来源规则，推进会停止。

手机窄屏验收仍挂起，没有新增性能提升承诺。代表性旅程通过不意味着所有随机分支穷举。
