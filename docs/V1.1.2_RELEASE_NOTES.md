# 斗罗人生模拟器 V1.1.2 更新说明

V1.1.2 是长局性能维护补丁，沿用 V1.1.1 的规则和存档语义。正式发布回执见 [GitHub Release](https://github.com/MaxwellGuoDUT/douluo-life/releases/tag/v1.1.2)，游戏入口仍为[根首页](https://maxwellguodut.github.io/douluo-life/)。

## 本版变化

- 普通V10推进中的完整会话复制由4份降至2份：先复用route提交保护，再将同一同步生命周期内的draw和commit合用一份私有回滚快照。独立公共调用仍默认自保护，保留非有限数和非JSON数据校验。
- 角色抽屉关闭时不重建详情列表，打开前同步刷新当前状态。
- 保留随机算法、权重、资格、效果顺序、年龄/寿命与终局规则，以及完整历史、事务回滚、最近一次重抽、暂停/取消和每批200次上限。

## 存档兼容

保持V1.1.0/V1.1.1的斗一 /8 语义和手动八槽格式，当前合法存档可直接读取。更早的不兼容档仍拒绝，不自动迁移；保留原始备份并在原版本继续。更新页面前请手动导出需要保留的人生，页面未保存的状态不会自动保存。

2026-10-20固定候选的完整回归408通过、0失败、0跳过，来源与资产检查通过；完整状态、所有历史、RNG、检查点隔离、重抽、失败回滚及存档往返对照通过。覆盖四路线的自然旅程或有界前缀；神考及海神继承继续人生含机制测试，不冒充新增自然稀有命中。桌面浏览器验收通过，用户对人工验收反馈“通过 检测完毕。”。
