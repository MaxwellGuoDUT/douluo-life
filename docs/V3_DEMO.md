# V3 最简人生 Demo（全量 provisional）

V3 是独立的临时可玩 Demo，不升级任何正式生产规则，也不改写用户源文件、任务书或 `outputs/` 材料。

## 流程

```text
0岁抽身份并立即生效
  -> 每次点击推进一年
  -> 6岁抽天赋并接入武魂觉醒
  -> 每年修炼，等级到10/20/.../90时抽魂环并触发临时魂骨概率事件
  -> 100级与固定战力1500的比比东战斗
  -> 成功或失败后结束游戏
```

启动本地 HTTP 服务：

```powershell
cd D:\0CODE\douluo-life
python -m http.server 8080
```

打开 `http://127.0.0.1:8080/v3-demo.html`。页面主区只有转盘、一个“抽取并推进一年”按钮和当前事件；状态、武魂、魂环魂骨、规则与审计记录位于右侧可折叠侧栏。

## 6 岁武魂接入

V3 的天赋值是武魂觉醒的唯一先天魂力输入，不会再次偷偷抽取另一个天赋值。6 岁非0级角色调用现有生产觉醒运行时，读取：

- `data/v2/content/age-6-awakening.json`
- `data/v2/catalogs/martial-souls.json`
- `data/v2/config/awakening-probabilities.json`

生产链负责按已确认流程抽取武魂数量、共享品质、形态和目录实体。生成的独一无二武魂实例写入 `player.martialSouls`，后续魂环挂到当前武魂实例，因此会被现有 `CombatPowerCalculator` 读取。生产输入保持 `production`，但 V3 接线和展示仍标记为 `provisional`。

0级在6岁直接进入旁观终态，不进入普通成长池，也不执行本 Demo 的武魂、魂环和魂骨流程。

## 年度事件

90级前沿用独立天赋系统的等概率普通成长池，负向成长使用已确认的大等级最低值约束。当前事件会显示具体抽取结果，例如：

- 当前事件直接读取 `data/config/talent.json` 中对应 E/D/C/B/A/S/god-level 普通成长条目的 `narrative` 原文，包含全部正向、零增长和负向结果。
- 乡下平民过滤负向结果后，仍显示被抽中的剩余普通结果原文；身份年度加成会在原文后追加说明。
- `-5`：心魔反噬，你的实力受到了重创，可降到当前大等级的最低级。
- `-2`：心魔经常在纠缠你，你的修为不进反退，可降到当前大等级的最低级。
- `-1`：你陷入了走火入魔，修为倒退1级，可降到当前大等级的最低级。

90级仍属于81–90级魂斗罗大等级；91级以后正式魂核成长池继续空置，V3 只使用显式标记的 `+1/年` provisional 过渡夹具走到100级。

## 魂环、魂骨和终局

10/20/.../90级突破沿用 `data/config/v3-demo.json` 指定的旧轮盘参考资料。魂环来源、年限解析、第八魂环的 `legacyWheelId=632` 临时引用，以及每次突破5%魂骨事件全部是 provisional。魂骨命中后读取旧轮盘 `legacyWheelId=71` 的临时奖励项。

0岁身份事件直接展示 `talent.docx` 中的身份叙述并立即生效。6岁武魂事件展示生产目录抽中的每个武魂名称、形态、品质和属性；这些叙述只用于 V3 过场展示，不改正式武魂目录。

100级使用现有战力计算器得到静态战力，与固定1500比较；胜利和失败都会写入终局事件并结束 Demo。转盘动画时长由 `data/config/v3-demo.json` 的 provisional `animation.durationMs=450` 控制，抽取逻辑不变。
