# 斗罗人生模拟器 V1.1.1 发布候选说明

状态：2026-10-15 本地候选，尚未提交、合并、部署或创建 tag/Release。线上正式版本仍以 GitHub Release 为准。

V1.1.1 修复海神独立九考在等待等级门槛时误入普通五年考核计划的推进异常。已有自然人类旅程从开局完成九考继承，并验证继续人生及主动飞升分支。

- 元素特质以中文显示极致属性、法则种子和完整法则；保留成长记事中的等级、阶数和品质，存档中的内部标识保持原样。
- 修复转盘旋转时撑宽窄屏页面的问题。
- 固定受版本绑定的文本资源换行，避免 Windows 工作区与 Git 部署字节不一致导致正常脚本被拦截；原 APK 模块字节保持原样。
- 原模块自行创建的预加载请求也纳入完整性校验，原样式失败时停止游戏启动。
- 页面按资源字节绑定脚本、数据和样式版本，并在支持的浏览器中校验完整性。资源失败会停止对应加载，原始槽位保留；不会自动刷新或清空存档。

## 存档与使用

保持 V1.1.0 的斗一 /8 语义及八槽格式，当前 V1.1.0 存档可直接读取。更早的 /5、/7 等不兼容档仍会拒绝，请保留原始 JSON 并在原版本继续。没有自动保存或迁移，未保存的人生请先手动备份再重开页面。

完整模块校验要求支持 import-map integrity：Chrome/Edge 127+、Firefox 138+、Safari/iOS Safari 18+（来源支持信息，不能替代实测）。不支持 import maps 的浏览器停止启动；仅支持 import maps 而缺少其 integrity 的旧浏览器仍可能启动，但模块完整性拦截不在本轮保证范围。建议使用新版浏览器。

## 验证及保留限制

自然海神九考有 Node、桌面生产入口及原始导出一致证据；修罗共存和停止其他神考属于机制证据。自然黄级资格及完成仍未命中，不推断不可达。

桌面窄视口覆盖 320×568、360×800、390×844、412×915 和横屏，390 覆盖四路线主要操作。用户报告 Android 15 Chrome 在已发布 V1.1.0 上的键盘、旋转、抽屉、后台恢复、JSON 往返和取消选择正常；本候选新增修复尚未真机复验，无 iOS 实测。

缓存混用在隔离环境复现并验证本地修复；Pages/CDN 升级验收尚未进行。部分来源仍可能安全中断，满魂骨后奖励没有明确规则时会保留状态停止，不补造结算。不宣称性能普遍提升。

自然证据轮实际累计从零启动 246 次，超过任务书 240 次上限 6 次；53,500 次推进和累计计时时间未超限。此偏差保留在审查材料中，本轮发布复核没有追加目标搜索。
