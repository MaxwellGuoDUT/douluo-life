## 存档与使用

保持 V1.1.0 的斗一 /8 语义及八槽格式，当前 V1.1.0 存档可直接读取。更早的 /5、/7 等不兼容档仍会拒绝，请保留原始 JSON 并在原版本继续。没有自动保存或迁移，未保存的人生请先手动备份再重开页面。

完整模块校验要求支持 import-map integrity：Chrome/Edge 127+、Firefox 138+、Safari/iOS Safari 18+（来源支持信息，不能替代实测）。不支持 import maps 的浏览器停止启动；仅支持 import maps 而缺少其 integrity 的旧浏览器仍可能启动，但模块完整性拦截不在本轮保证范围。建议使用新版浏览器。

## 验证及保留限制

自然海神九考有 Node、桌面生产入口及原始导出一致证据；修罗共存和停止其他神考属于机制证据。自然黄级资格及完成仍未命中，不推断不可达。

既有桌面窄视口覆盖 320×568、360×800、390×844、412×915 和横屏，390 覆盖四路线主要操作。部署后另验390×844、844×390及四路线开局；公开页面201步快照严格恢复、原样导出和刷新后主动读取通过。用户本轮对新版 Android 15 Chrome 复验回复“新版均正常”，覆盖中文特质、转盘/抽屉、键盘/旋转、后台恢复及 JSON 往返/取消选择；手机型号和精确 Chrome 版本未提供。无 iOS 实测。

缓存混用在隔离环境复现并验证失败保护；Pages 的112个运行文件、含带版本 URL 共222次响应与候选字节一致。升级前旧标签页跨部署续跑未验；桌面201步恢复后的结算显示奖励，但随后新人生操作遇到控制超时，未确认该次续跑最终结果。部分来源仍可能安全中断，满魂骨后奖励没有明确规则时会保留状态停止，不补造结算。不宣称性能普遍提升。
