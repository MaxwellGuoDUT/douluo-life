# 临时魂环抽取 Demo（provisional）

## 定位

本 Demo 是 Day16 的临时可玩验证页，不是正式魂环生产系统。所有新增配置、流程、年限解析、手动选择语义和吸收结果都明确标记为 `provisional`，不得升级为 production 规则。

它只读取 `data/reference/legacy-wheel/wheels.normalized.json`。该目录本身仍是旧版转换资料，保留 `REFERENCE DATA ONLY` 边界；本 Demo 不修改旧版转盘源文件，也不接入 V1/V2 Player、Annual Flow、战力计算或存档。

## 手动流程

请从仓库根目录通过本地 HTTP 服务打开页面（直接双击 `file://` 可能阻止模块和 JSON 请求）：

```powershell
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/soul-ring-demo.html`。

1. 打开仓库根目录的 `soul-ring-demo.html`，输入测试等级和第 1～9 魂环槽位。
2. 点击开始。等级 0 直接进入 `ignored` 终态，不抽轮盘；低于临时门槛 10 级会报触发条件未满足。
3. 同一槽位存在多条旧版路线时，手动选择来源轮盘。第八魂环若没有旧资料来源，页面保留未决状态。
4. 载入候选项后，可以手动选择；只有全部权重明确且存在正权重的旧版轮盘才显示可用的正权重临时抽取。零权重项继续保留在源资料中，但不可选；`null` 权重项只能手动选择，不猜测概率；混合权重轮盘只允许手动选择。
5. 年限范围由旧版文本临时解析。固定年限可以直接确认，范围和无法解析的文本必须手动输入合法年限。
6. 进入吸收阶段后，手动选择“成功”或“失败”；两者都会显示对应结果并结束本次 Demo。成功才把临时魂环写入 Demo 内存状态，失败不写入。

页面会保留过场信息、warnings 和 history，便于检查来源、状态和每一步是否仍是 provisional。

## 测试夹具边界

`18000` 年只允许通过运行时的显式 `testFixedYears: 18000` 测试参数使用，且必须同时标明 `testOnly: true`。浏览器页面不会自动注入这个固定值；页面输入仍受候选文本范围和最低 10 年校验约束。

## 尚未正式确定的内容

- 正式魂环触发节点、角色上下文和魂环槽位路由。
- 旧版 WheelID 之间的正式后继关系；旧资料没有保存 `itemNextWheelId`。
- 年限抽取的正式概率、魂兽选择、血脉/品质、吸收成功率、失败后果和重试规则。
- 第八魂环及更高层级的正式生产来源。
- 与 V1/V2 Player、年度流程、魂环战力和存档的接入。

这些内容保持未决或仅作为 reference/provisional，不在本 Demo 中自行设计。
